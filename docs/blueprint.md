# **App Name**: Turnomatic

## Core Features:

- Appointment Scheduling: Allow users to schedule appointments for specific services or time slots.
- TV Display: Display the current turn on a TV screen, updating automatically as turns progress.
- Turn Management: Manage and update the status of turns as they are attended to.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and calming feel.
- Secondary color: Light gray (#E0E0E0) for backgrounds and subtle UI elements.
- Accent: Amber (#FFBF00) for highlighting the current turn and important actions.
- Clean and straightforward layout for easy navigation and clear information display.
- Simple, recognizable icons for appointment types and actions.
- Smooth transitions and subtle animations to indicate changes in turn status.
